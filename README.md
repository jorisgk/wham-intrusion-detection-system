# WHAM Intrusion Detection System

Protect your Home Assistant media players from unwanted music.

WHAM Intrusion Detection System (WHAM IDS) monitors selected media players and checks the current track title and artist against a configurable blocklist. When a match is found, it can announce a warning through Home Assistant Text-to-Speech and mute the affected player. When a non-matching track starts, WHAM IDS unmutes a player that it muted itself.

## Features

- Select one or more Home Assistant media players.
- Block multiple artist names.
- Case-insensitive matching against `media_title` and `media_artist`.
- Optional Text-to-Speech announcement with a configurable TTS entity, language, and message.
- Automatically mute a matching player and unmute it when a different track starts.
- Dashboard entities for enabling/disabling protection, editing the blocklist, and showing detection status.
- Does not intentionally take over a player that was already muted before a match was detected.

## Requirements

- Home Assistant with support for custom integrations.
- At least one configured `media_player` entity.
- For spoken announcements, a configured Home Assistant TTS integration that provides a TTS entity.

## Installation with HACS

1. Open **HACS** in Home Assistant.
2. Open the three-dot menu and choose **Custom repositories**.
3. Add `https://github.com/jorisgk/wham-intrusion-detection-system`.
4. Select **Integration** as the category.
5. Add the repository and install **WHAM Intrusion Detection System**.
6. Restart Home Assistant.

After installation, add the integration from **Settings → Devices & services → Add integration** and search for **WHAM Intrusion Detection System**.

## Manual installation

1. Download the latest release archive from the [GitHub Releases page](https://github.com/jorisgk/wham-intrusion-detection-system/releases).
2. Copy the `custom_components/wham_intrusion_detection_system` directory into your Home Assistant `config/custom_components/` directory.
3. Restart Home Assistant.
4. Add **WHAM Intrusion Detection System** from **Settings → Devices & services → Add integration**.

## Configuration

When adding the integration, give it a name. Then open the integration's **Configure** option to set:

- **Media players**: select the media players WHAM IDS should monitor.
- **Artists**: enter one blocked artist per line. The default list contains `Wham!`.
- **TTS enabled**: enable or disable the spoken warning.
- **TTS entity**: select the TTS entity to use for announcements.
- **TTS language**: for example, `en-GB`.
- **TTS message**: customize the warning spoken when a match is detected.

If TTS is disabled or no TTS entity is selected, WHAM IDS will mute the player without an announcement.

## Entities

The integration provides entities to control and observe protection:

- `switch.wham_ids_beveiliging`: enable or disable WHAM protection.
- `text.wham_ids_geblokkeerde_artiesten`: edit the blocked artists (separate names with commas).
- `binary_sensor.wham_ids_detectie`: turns on when a blocked track is detected.

Entity IDs are generated by Home Assistant. If your IDs differ, check **Settings → Devices & services → Entities** and adjust the dashboard YAML below.

## Add the dashboard card

You can add the example below as a single dashboard card. It includes the protection switch, the blocked-artists text field, and a flashing alert that only appears while a blocked track is detected.

### Steps

1. Open the Home Assistant dashboard where you want the controls.
2. Select **Edit dashboard**.
3. Select **Add card**.
4. Choose **Manual** (YAML mode).
5. Paste the complete YAML example below and save.

### Optional dependency: button-card

The flashing alert uses the community [`custom:button-card`](https://github.com/custom-cards/button-card). Install that card separately and make sure it is loaded as a dashboard resource. If you do not want to install button-card, you can remove the conditional alert section from the YAML and keep the standard entities card.

### Complete dashboard YAML

```yaml
type: vertical-stack
cards:
  - type: entities
    title: WHAM Intrusion Detection System
    show_header_toggle: false
    entities:
      - entity: switch.wham_ids_beveiliging
        name: Protection
        icon: mdi:shield-check
      - entity: text.wham_ids_geblokkeerde_artiesten
        name: Blocked artists
        icon: mdi:music

  - type: conditional
    conditions:
      - entity: binary_sensor.wham_ids_detectie
        state: "on"
    card:
      type: custom:button-card
      entity: binary_sensor.wham_ids_detectie
      name: INTRUSION DETECTED
      icon: mdi:alert-octagon
      show_state: false
      tap_action:
        action: none
      hold_action:
        action: none
      styles:
        card:
          - background-color: "#cc0000"
          - border: 3px solid "#ffeb00"
          - border-radius: 12px
          - padding: 20px
          - animation: wham-blink 1s infinite
        name:
          - color: "#ffeb00"
          - font-size: 24px
          - font-weight: 900
          - text-align: center
        icon:
          - color: "#ffeb00"
          - width: 45px
        grid:
          - grid-template-areas: '"i" "n"'
          - grid-template-columns: 1fr
          - grid-template-rows: auto auto
      extra_styles: |
        @keyframes wham-blink {
          0%, 100% { opacity: 1; }
          50% { opacity: 0.45; }
        }
```

The alert card is conditional: it is hidden when `binary_sensor.wham_ids_detectie` is off and appears when a blocked track is detected. The alert clears when detection ends.

If Home Assistant generated different entity IDs, replace the three IDs in the YAML with the IDs shown in your instance.

## How it works

WHAM IDS listens for state changes from the selected media players. It searches the current track title and artist for any configured blocked artist name, without case sensitivity.

When a match is found, WHAM IDS attempts the announcement (if configured) and then mutes that player. When a later state change reports a non-matching track, the integration unmutes the player if WHAM IDS muted it.

Turning protection off clears the detection indication and attempts to unmute players muted by the integration.

## Troubleshooting

- **No detection:** confirm that the media player is selected in the integration options and that its state attributes contain `media_title` or `media_artist`.
- **No announcement:** verify that the selected TTS entity works independently in Home Assistant and that TTS is enabled.
- **Player does not mute or unmute:** check whether the media player integration supports the `media_player.volume_mute` service.
- **Need help?** Please open an issue and include your Home Assistant version, the affected media player integration, relevant log messages, and steps to reproduce. Do not include tokens, passwords, or other secrets.
